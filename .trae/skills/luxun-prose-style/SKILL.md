# 鲁迅散文风格写作

## 目标

输入题材、素材或一句需求，产出 1 篇该文体下风格自洽的中文散文。默认在对话中输出正文；指定路径时才写盘。

## 项目内接入

本项目的散文页（`/prose`）与本技能共用同一份风格档案：

- 请求参数：`task=prose`、`params.style=luxun`、`params.emotion`（≤200 字）、`params.recent_state`（≤1000 字，emotion 与 recent_state 至少其一）、`context.image_urls`（可选，0–5 张）。
- Python 服务读取 `鲁迅散文风格配置.json` 装配提示词，本技能提供同一套流程约束，二者不得各写一套规则。
- 输出契约：Markdown，首行 `# 标题`，正文 800–1500 字（散文诗 ≤800 字），经 SSE 的 `delta` / `done` 帧返回；不输出创作说明、要点列表或对话。
- 图片可选：有图时图片是引子不是说明对象，至少取 1 个画面中的具体物象（颜色、光影、物件、姿态），不得逐张描述，不写“照片里”“这张图”；无图时从文字素材（情绪、近况）中的具体人事或物件起笔，仍须选定 1 个贯穿物象。

## 前置条件

必需：
- 风格配置：`f:\AI_Blog\鲁迅散文风格配置.json`（根目录同名文件；部署时可用环境变量覆盖）
- 文体类型：回忆性叙事散文 / 悼念性散文 / 散文诗（象征性抒情）

缺失时的处理：
- 文体未指定 → 按下方信号判型；题材仍不明确时只追问一次，之后按回忆性叙事散文处理。
- 篇幅未指定 → 散文 800–1500 字，散文诗不超过 800 字。
- 素材不足 → 可基于题材虚构日常细节；涉及真实人物、事件、引文时禁止编造。
- 配置无法读取 → 停止生成并索要路径，禁止凭记忆复原规则。

## 流程

1. **读取配置**：确认 `language / syntax / narrative / structure / rhetoric / emotion / thought_progression / ending / conditional_features / avoid_patterns / adaptation_rules` 字段存在。
2. **判型**：按信号确定主导文体，同时列出禁用项。
   - 回忆性叙事散文：有明确旧事、人物、地点、时间；留暖意，儿童视角可用。
   - 悼念性散文：死亡、离别、纪念；先蓄势后爆发，可用数字分节。
   - 散文诗：无具体事件，以情绪与意象为主；冷峭，禁用儿童视角与分节。
3. **选要素（硬预算）**：`language`≤2、`syntax`≤2、`narrative`≤2、`rhetoric`≤2、`emotion`=1 条基调、`thought_progression`≤1、`ending`=1、`structure`=1 个骨架。`confidence=medium` 的条目全篇合计≤2。
4. **换算语汇**：现代题材先过 `adaptation_rules`；辫子、书塾、长毛等旧物象不得硬搬；文白虚词每段≤2–3 处。
5. **搭骨架**：采用“现在—回忆—现在”回环；开篇写“现在”的一个空镜头；选 1 个贯穿物象承载题旨。
6. **起草**：逐条执行所选条目的 `writing_rules`。同一段落不得同时铺开 3 条以上修辞规则；白描后立即推进叙事，不补心理分析。
7. **收束**：从 `ending` 四条中选 1 条，末句回扣开篇物象并叠加一层新判断；收束即止，不补总结段。
8. **自检**：逐条核对下方清单，不通过就地修改，不得交付带标记的草稿。

## 硬约束

- NEVER 触犯 `avoid_patterns` 任一条：抽象评价标签、通篇文言化、点破反语、情绪一路高亢、解释象征、单一“战斗语气”。
- NEVER 混用不同文集的笔法：温情克制的《朝花夕拾》笔法与《野草》的孤峭独白不得同篇并置。
- NEVER 在正文中出现“鲁迅风格”“模仿”“反讽”等元评论；反语不加引号、不作注解。
- NEVER 成句复用鲁迅原文；只迁移手法，不复刻句子。
- NEVER 逐张解说图片，或把图片写成说明对象。
- MUST 三类文体分温处理：回忆文留暖意，悼念文蓄势后爆发，散文诗以意象承载情绪。
- MUST 抒情克制：强烈情绪改用身体化比喻或冷硬判断，不写“我很痛苦”式直陈。
- MUST 议论紧贴事实：先写足 1–2 个具体细节，议论只就这些细节展开。

## 输出格式

- 只输出标题与正文，不写创作说明、要点列表或分析。
- 分节（一、二、三）仅用于悼念文或 1500 字以上长文；散文诗不分节。
- 需要说明时，正文后另起“风格说明”，不超过 150 字，只列所用条目名，不复述配置原文。

## 示例（改写方向）

- 反例：我很伤心，想起奶奶，眼泪一下子流了下来。
- 正例：灶台上的搪瓷缸还留着半圈茶垢；我伸手去擦，指尖是凉的。
- 要点：删掉情绪形容词，换成可触摸的物与身体感受；判断留给读者。

## 自检清单

- [ ] 文体判定明确，且未使用该文体的禁用项
- [ ] 开篇是“现在”的空镜头，结尾回扣同一物象
- [ ] 有 1 个贯穿物象承载题旨，且参与叙事推进而非仅作道具
- [ ] 至少 1 个具体物象来自图片，且没有逐张描述
- [ ] 人物以 2–3 个外貌/动作标签呈现，白描后未补心理分析
- [ ] 关键转折处短句煞尾，长句铺陈在前
- [ ] 无一处点破反语、解释象征或替读者总结
- [ ] 情绪未直陈，至少有一处身体化比喻或冷硬判断
- [ ] 无鲁迅原文成句复用
- [ ] 文白虚词每段≤3 处，无“却/然而”堆叠、无无对象的名词清单
- [ ] 正文长度符合文体要求，且没有创作说明混入正文

## 失败与降级

- 用户反馈“不像”或“再鲁迅一点”：先判断偏差落在文体判型、修辞密度、情绪基调的哪一项，只调整该项，不得整体加码。
- 配置与用户要求冲突（例如要求直白煽情）：以用户要求为准，交付时说明偏离了哪条约束。
- 生成超过 2500 字：按 `structure` 的数字分节重组，避免平铺直叙。
- 改写存量文章：保留原文事实与信息，只替换表达层，不新增情节。
- 图片与文字素材冲突：以文字素材为叙事主线，图片只提供物象与氛围。

## 参考

- 风格数据：`鲁迅散文风格配置.json`，字段含 `language`（用词）、`syntax`（句法）、`narrative`（叙事）、`structure`（结构）、`rhetoric`（修辞）、`emotion`（情感）、`thought_progression`（思路推进）、`ending`（结尾）、`conditional_features`（条件性特征）、`avoid_patterns`（禁用模式）、`adaptation_rules`（现代迁移）、`limitations`（适用边界）。
- 适用边界见 `limitations`：仅基于十篇散文归纳，不适用于小说与杂文；`confidence=medium` 的条目需复核，不可当作定论。
